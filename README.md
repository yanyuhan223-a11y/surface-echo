## 这是什么

你扮演灯塔猎荒者小队指挥官 **马克**，独自下到被玛娜生态覆盖的地表。
在一座废弃的地下车站里搜寻物资、追踪一段来源不明的信号，
躲避受情感与信息素吸引的噬极兽，并遇见一个不该存在于此的少女——**樰**。

一段 5–10 分钟的氛围叙事体验（narrative vertical slice）。

## 玩法要素

- **自由探索**：纵深废弃车站、隧道、换乘大厅，手电筒与脉冲扫描辅助搜索
- **物资搜寻**：散布场景的集装箱、医疗柜、猎荒者遗骸等，可搜集并附带世界观碎片
- **NPC 与任务**：三条委托线，接取 → 目标追踪 → 完成 → 回报
- **潜行躲避**：噬极兽巡游时需蹲伏进入阴影、保持安静
- **信号同步 QTE**：限时相位锁定，成败对应不同结局
- **多结局**：由任务完成度与关键补给回收量决定

## 技术栈

- **Three.js** — 第一人称 3D 场景、光照、雾、粒子
- **postprocessing** — UnrealBloom、ACES 色调映射、色差 / 暗角 / 胶片颗粒
- **Blender（无头程序化建模）** — 场景与道具资产，导出 GLB
- **WebAudio** — 程序化合成风噪、低频轰鸣、脚步、扫描、警报与兽吼
- **Vite + React** — 构建与 UI 层
- 生成式 AI 制作的原创贴图与角色 / 生物美术

## Blender 资产管线

场景与道具由 Blender 脚本程序化生成，非手工建模：

```bash
blender --background --python tools/blender/build_assets.py
```

流程：基元 → 顶点噪声形变（锈蚀 / 破损）→ bevel 倒角 → 布尔切口 → Smart UV 展开 → 材质插槽 → 导出 GLB。

GLB 内不打包贴图，仅保留 `MAT_CONCRETE` / `MAT_METAL` / `MAT_HAZARD` / `MAT_PIPE`
材质插槽名，由前端映射到项目内的程序化 PBR 材质，以减小体积并统一风格。
