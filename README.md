# 地表回声 / Surface Echo

一款以“探索 + 剧情创作”为核心的第三人称 WebGL 概念游戏。

玩家在废弃传送大厅中调查回声碎片，并在中央叙事重构台选择自己相信的真相。不同选择会改变灯光、目标与大厅结局。

## 操作

- `WASD` / 方向键：移动
- `Shift`：奔跑
- 拖动鼠标或触屏右侧：旋转镜头
- `E` / 交互按钮：调查线索与操作控制台
- `V`：切换俯瞰视角
- `Esc`：暂停

移动端支持竖屏第三人称构图、虚拟方向键、触屏镜头与安全区适配。

## 本地运行

```bash
npm install
npm run dev
```

默认访问 `http://127.0.0.1:5173`。

## 构建与测试

```bash
npm run build
npm test
```

## 技术栈

React、TypeScript、Three.js、Vite。
